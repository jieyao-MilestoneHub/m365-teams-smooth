# Status Dashboard (Power BI) — FAQ

> Near-miss by design: this is about a *dashboard tool*, not the Status Reporting Policy. It shares
> the words "status", "report", "weekly" but answers tool questions, not the policy on what a report
> must contain or where it is published.

## What is the Status Dashboard?
The Status Dashboard is a Power BI workspace that visualizes delivery metrics — burndown, cycle time,
open-issue counts — refreshed nightly from the data warehouse.

## How do I get access?
Request the "Delivery Metrics" Power BI role from IT. Access is read-only for most roles.

## Why don't the numbers match my weekly report?
The dashboard refreshes nightly and may lag the live trackers by up to a day. The weekly status report
is authored from the live systems of record at report time; the dashboard is a convenience view, not
the system of record.

## Can the dashboard replace the weekly report?
No. The dashboard is a visualization; the weekly status report (a channel post) remains the record.
