What this view shows

The platform map. Users meet the court in Microsoft 365 Copilot Chat / Teams through a declarative agent and the Change Court Adaptive Card; the Microsoft 365 Agents Playground offers the same card surface with no tenant at all. Behind the backend, Azure AI Foundry supplies both the reasoning model (Azure OpenAI) and the grounded knowledge (Foundry IQ over Azure AI Search); Microsoft Graph and the GitHub API supply evidence and carry approved writes. Each edge is labeled with its authentication posture.

Design rationale

  • Meet users where the decision happens. The declarative agent puts the court inside Copilot Chat and Teams; the Adaptive Card is the decision UI. There is no separate web app to deploy, secure, or train people on.
  • Two entries, one behavior. A real tenant and the Agents Playground drive the identical backend, card payloads, and approval flow — so the full experience can be exercised, rehearsed, and demonstrated before any tenant exists.
  • Foundry carries both halves of intelligence. Azure OpenAI powers the agentic roles (parsing, drafting); Foundry IQ grounds the impact evidence in a knowledge base with citations. Both authenticate keylessly through managed identity — no API key exists to leak.
  • Reads before writes. Microsoft Graph supplies real calendar and SharePoint evidence; Graph writes remain mocked or dry-run until promoted deliberately, system by system, in configuration.
  • The platform is swappable at the edge. Every box on the bottom row sits behind the same adapter port — which is why the diagram looks the same whether a system is real or mocked.

Key guarantees

  • No stored key for Azure AI Foundry services — managed identity only.
  • Remaining credentials (GitHub token, Graph app registration) live in the host's secret store, never in the repository.
  • One configuration switch forces every integration to mock: the entire pipeline runs with zero external credentials.
  • Copilot, Teams card actions, and the Playground all resolve to the same business layer — no surface-specific behavior.
