Notes

  • The decision core (services/, agent/) imports only ports; all SDK, database, and LLM specifics live in adapters/.
  • A new integration is one adapter module plus one registration — the graph, services, REST, and MCP are untouched (open/closed). Real-vs-mock is chosen per system from configuration.
  • One business layer serves every surface, so the card, MCP, and REST behave identically. The only web surface is a read-only run page behind signed links — no dashboard.
