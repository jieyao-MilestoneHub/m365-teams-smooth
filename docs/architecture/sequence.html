Notes

  • The gates run in the service layer, not the UI, so a card button, an MCP tool, or any future surface follows the same single path — no privileged shortcut.
  • Submitting returns immediately; the decision may arrive hours later from a different process. Resume happens from the checkpoint, so no server has to stay alive across the gap.
  • Quorum is derived from the impact evidence tags and resolved to identities through a configured approver directory — changing who approves what is configuration, not code.
