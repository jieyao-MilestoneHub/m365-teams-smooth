Notes

  • Dry-run is a state field, not a separate path: in DRY_RUN the execute node predicts effects and performs no writes.
  • The verdict gate is a durable interrupt — the run is checkpointed by thread_id and resumed when a verdict is cast; casting the same verdict twice is idempotent (no double execute).
  • Reads (impact) and writes (execute) reach every system only through adapters behind ports; the capability registry blocks unsupported actions at intake before anything is planned.
