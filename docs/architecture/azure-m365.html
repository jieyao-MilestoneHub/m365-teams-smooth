Azure / M365 architecture diagram

Where the system meets the platform: Copilot Chat and Teams in front, Azure Container Apps hosting the backend, and Azure AI Foundry, Microsoft Graph, and GitHub behind it — every credential explicit, keyless where the platform allows.

Notes

  • The declarative agent puts the court inside Copilot Chat and Teams; the Adaptive Card is the decision UI. There is no separate web app to deploy, secure, or train people on.
  • Azure AI Foundry authenticates keylessly through managed identity — no API key to leak. Remaining credentials (GitHub token, Graph app registration) live in Azure Key Vault, never in the repository.
  • Every box on the bottom row sits behind the same adapter port, so the diagram is unchanged whether a system is real or mocked.
